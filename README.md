# Hellraiser: Revival 製品版 日本語化パッチ

Clive Barker's Hellraiser: RevivalのWindows／Steam製品版向けに開発している非公式日本語化パッチです。

**デモ版をお持ちの方へ:** [デモ版向け日本語化パッチのリポジトリ](https://github.com/zombine04/hellraiser-revival-japanese-patch-demo)をご利用ください。デモ版の導入手順と配布ZIPはそちらに掲載しています。

## 開発状況

現在は開発準備段階で、製品版用の配布ZIPはまだありません。デモ版のGit履歴・訳文・開発基盤を引き継ぎ、ビルド・導入処理の製品版対応と実機検証をこれから行います。デモ版での確認結果は、製品版での動作確認を意味しません。

初回の正式公開は、全編の翻訳・製品版の通しプレイ・最終承認後を予定しています。音声と画像に描かれた文字は対象外です。

## 公開後の導入手順（予定）

1. ゲームを終了します。
2. [Releases](https://github.com/zombine04/hellraiser-revival-japanese-patch/releases)から製品版用の配布ZIPをダウンロードし、ZIP全体を通常のフォルダーへ展開します。
3. `Install.cmd`を実行します。
4. 導入後にゲームを起動し、言語設定で**「日本語」**を選択します。

製品版での検証結果に合わせて、正式公開前に手順を確定します。日本語表示には簡体字中国語の言語枠と、ゲーム同梱のNotoSansJPを利用する予定です。

## 開発

開発ブランチは `develop`、公開ブランチは `main` とします。Issueごとに作業ブランチを作り、検証後にdevelop宛てのPRを提出します。mainへの統合とリポジトリの公開は、通しプレイと最終承認後に行います。

GitHub Actionsは引き継いだ基盤の検証に使用します。製品版対応が完了するまで、CIの検証用成果物は製品版の正式配布物として扱いません。リリース処理はmain限定で実行し、mainの作成・統合は最終承認後に行います。

原文・抽出資産・個人パス・実機ログは `.local/` に保管し、GitやGitHubにはアップロードしません。公開する翻訳データは、日本語訳と必要な識別情報のみとします。
