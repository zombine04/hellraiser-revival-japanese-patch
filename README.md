# Hellraiser: Revival 製品版 日本語化パッチ

Clive Barker's Hellraiser: RevivalのWindows／Steam製品版向け非公式日本語化パッチです。ゲーム内のUI・字幕・文書を日本語にします。音声と画像に描かれた文字は対象外です。

**デモ版をお持ちの方へ:** [デモ版向け日本語化パッチ](https://github.com/zombine04/hellraiser-revival-japanese-patch-demo)をご利用ください。製品版用とデモ版用のパッチは別々に配布しています。

## 対応版と確認範囲

- 対応ゲーム版: `1.0.1.227219_HellraiserGame_Shipping_27809_ReleasePatch1_Test`
- 翻訳対象: Game 6,846件とEngineの入力表示164件、計7,010件
- ゲーム同梱のNotoSansJPを使用。フォント本体は配布物に含みません

デモ版から原文・識別情報・書式が一致する訳文を引き継ぎ、製品版の追加・変更分を翻訳しています。ユーザーがメニューとプレイした範囲の翻訳表示・内容を確認しています。全編の通しプレイ、全分岐、全解像度での確認は未完了です。詳細は[確認記録](https://github.com/zombine04/hellraiser-revival-japanese-patch/blob/develop/docs/release-candidate.md)を参照してください。

## 導入

1. ゲームを終了します。
2. [Releases](https://github.com/zombine04/hellraiser-revival-japanese-patch/releases)から `Hellraiser_Revival_Japanese_v1.1.0.zip` をダウンロードします。「Source code」のZIPは導入用ではありません。
3. ZIP全体を通常のフォルダーへ展開し、`Install.cmd` を実行します。
4. Steamの製品版が自動検出されます。見つからない場合は、製品版のインストール先を指定します。
5. 統合パッチの生成・検証が完了してからゲームを起動し、言語設定で**「日本語」**を選択します。

日本語表示には簡体字中国語の言語枠を使用します。パッチ適用後のゲーム内では、この選択肢が「日本語」と表示されます。初回設定前の通知には英語が残る場合があります。

導入時にゲーム原本の必要な範囲だけを読み、ニュース・日時の変更をフォント設定と同じコンテナへ統合します。Python・.NETの追加導入や、導入中のネット接続は不要です。ニュースは英語、セーブ日時は `YYYY-MM-DD` / `HH:mm:ss` の数字・24時間表記になります。

ゲーム版または対象データが一致しない場合は、既存パッチを変更せず中止します。ゲーム更新後は最新の対応情報を確認してください。デモ版や製品版と確認できないフォルダーには導入できません。

## 更新・削除

更新するときはゲームを終了し、新しい配布ZIPを展開して `Install.cmd` を実行します。パッチが管理している3ファイルだけを更新します。実機確認済みのニュース・日時試作が残っている場合は、ハッシュを照合して統合版へ移行します。未知・改変・欠落した試作は削除せず停止します。

削除するときはゲームを終了し、配布ZIPに含まれる `Uninstall.cmd` を実行します。ゲーム本体やセーブデータは削除しません。削除後、簡体字中国語の表示へ戻ります。

通常の処理失敗では導入前の状態へ戻します。強制終了・電源断や復元失敗時の退避データは、ゲームフォルダーの `.local/hellraiser-japanese-patch/` に残ります。ゲームを起動する前に、該当作業フォルダーの `backup` 内にある同名ファイルを `Hellraiser/Content/Paks` へ戻してください。作業前の管理情報がない新規導入では、このパッチ名の3ファイルと管理情報のみを取り除きます。原本や他MODは変更しません。判断できない場合は退避データを保持して報告してください。

「別の処理が実行中」と表示された場合は、ほかの導入・削除処理が終わっているか確認します。異常終了で残った場合だけ、ゲーム内の `Hellraiser/Content/Paks/.hellraiser-revival-japanese-patch.lock` を削除して再実行してください。管理情報の `.json` や元ゲームのコンテナは削除しないでください。

## 既知の制限

- ニュースの英語化と日時の数字表記は、日本語以外の言語を選んだ場合も適用されます。
- 対応版専用です。未対応版へ強制適用することはできません。

- 初回設定前のシェーダー準備・デモセーブ引き継ぎ確認に英語が残るとの報告があります。
- シェーダー画面の装飾タグ露出に対して改行処理を修正していますが、該当画面での再確認は未完了です。
- 音声、画像内の文字、起動失敗・クラッシュなどの診断表示は対象外です。

## 開発

開発は `develop`、公開は `main` です。Issueごとに作業ブランチを作り、検証後にdevelop宛てのPRを提出します。mainへの統合とリポジトリの公開は、候補と確認範囲に対するユーザーの最終承認後に行います。

GitHub ActionsでWindows・Linuxのビルド・配布物検査・環境間一致を確認します。リリース処理はmain限定です。原文・抽出資産・個人パス・実機ログは `.local/` に保管し、GitやGitHubへアップロードしません。
