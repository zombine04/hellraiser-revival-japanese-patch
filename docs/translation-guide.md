# 翻訳方針

## 基準

英語原文を基準に、日本語として自然に読める文章へ訳します。中国語はキーと収録範囲の比較に使い、重訳の基準にはしません。原文、抽出物、文脈確認用の記録はローカルに保管します。

映画の痛みと快楽、欲望と信仰が交わる不穏さを保ちます。残酷な表現を婉曲化せず、原文にない残酷さも加えません。魔道士の台詞では静かな確信と儀式の響きを重視し、すべての人物に古風な言葉遣いを当てはめないようにします。特定の日本語字幕・吹替台本を転載しません。

設定確認には[ゲーム公式サイト](https://saber.games/hellraiserrevival/)と[原作者公式サイトの映画解説](https://clivebarker.info/hellraiser.html)を用います。箱の呼称は[原作者公式サイトの脚本に関する解説](https://clivebarker.info/hellraiserb.html)も参照します。これらは設定の参考資料です。本パッチの訳語・口調は翻訳上の判断であり、公式日本語訳と称しません。

## 媒体ごとの書き方

| 種類 | 方針 |
|---|---|
| UI・設定 | 行動と結果がすぐ分かる短い表記。動詞・名詞を画面の用途に合わせ、同じ操作の呼称を統一する |
| 操作説明 | 押す・長押し・切り替えの違いを省略しない。入力アイコンと条件を保持する |
| 字幕 | 発話の意図と感情を優先。英語の主語や呼びかけを機械的に繰り返さず、表示時間に収まる長さへ整える |
| 文書 | 書き手の教養、時代感、信仰、精神状態を反映。すべてを会話調にしない |
| アイテム | 名称と説明、目的表示、字幕中の呼称を照合。効果や数量を変えない |
| 規約・法的表記 | 権利者名、商標、URL、条件を勝手に変更しない。意味の確認が必要な項目は要確認のまま残す |

字幕は固定の文字数だけで機械的に分割せず、句のまとまりと実際の画面で判断します。短い発話は句点を省くことを基本とし、長文や文書では句読点を用います。三点リーダーは「…」、疑問符・感嘆符は全角を基本に、連続記号は感情に必要な範囲へ抑えます。改行の追加は表示確認後に行い、元から意味のある改行を維持します。

## 人物の口調

以下は初期基準です。場面、相手、実際の音声に合わせて調整します。

| 人物・役割 | 口調の基準 |
|---|---|
| エイダン | 一人称は基本「俺」。現代の砕けた口語。恐怖・怒りで短く途切れる発話と、サニーへの親しさを分ける |
| サニー | 率直で親しい口語。誘惑、冗談、不安を文脈で分け、機械的な女性語を足さない |
| ピンヘッド／地獄の司祭 | 抑制された断定と命令。威厳は語彙と間で示し、無意味な古語や説明口調を足さない |
| 魔道士 | 人間と異なる価値観を保つ。同じ信条でも人物ごとの温度差は残す |
| フォールン | 静かに誘い、確信をもって問いかける。契約条件の否定・留保を崩さず、からかいと儀式的な宣告を分ける |
| ブルーノ | 芸術家としての尊大さと、芝居がかった親しさ。「私」を基本とし、相手や力関係で敬語が変わることを保つ |
| マーロウ | 指導者としての断定と宗教的な高揚。演説と個人的な会話を区別し、力を失った場面でも同じ人物としてつなぐ |
| ゾーラ | 「あたし」を基本とする歯切れのよい口語。商人の呼び込み、皮肉、忠告を使い分ける |
| 教団員 | 崇拝・服従の語彙と粗暴な罵倒を場面で使い分ける。一般客と混同しない |
| 被害者・客・警官 | 職務や窮状に応じた口語。役割名だけで性別、一人称、人格を決めない |
| 日記・手紙の書き手 | 宛先、書かれた時期、後に判明する事実を照合し、プレイヤーがまだ知らない情報を補わない |

話者名は表示用の名前を基準とします。内部キーに人物名が含まれていても、画面上で称号や匿名の役割になっている場合、その情報を先回りして明かしません。

## 代表的な書き方

以下は方針を説明する自作例です。ゲームや映画の原文・台詞を引用したものではありません。

| 用途 | 日本語例 | 意図 |
|---|---|---|
| 設定 | 字幕を表示 | 操作内容を短く示す |
| 確認 | 保存していない変更を破棄しますか？ | 結果を明示する |
| 切迫した会話 | 待て。そこから動くな | 直訳調の主語を省く |
| 儀式的な宣告 | 扉は開いた。代償を捧げよ | 簡潔な断定で威圧感を出す |
| 日記 | あの音は、今夜も壁の向こうから聞こえる。 | 書き手の視点を保つ |
| 操作説明 | {Action}を長押しして調べる | 変数と長押しの意味を保持する |

## データとレビュー

名前空間・キー・原文ハッシュを翻訳の識別単位にします。同じ文章が複数のキーにあっても、話者や用途が異なる場合は個別に判断します。収録キー数は製品版で実際に表示される件数と区別します。

- `untranslated`: 未訳。原文で日本語欄を埋めない
- `needs_review`: 訳はあるが文脈・表記・表示などの確認が残る
- `reviewed`: 原文との意味・形式照合が済み、残る懸念を記録していない
- 意図的に英字を維持する名称や製品名には、その理由を記録する
- 文章レビューと実機表示確認は別々に記録する。`reviewed`だけで実機確認済みとはしない

翻訳時に変数、書式指定、タグ、入力アイコンを照合し、レビュー時には主語・否定・条件・数値・話者・呼称を再確認します。原文ハッシュが変わった項目は再確認対象へ戻します。字幕の省略は意味、人物関係、伏線を落としていないか確認します。原語のまま残った項目は検索により検出し、理由のない未訳として扱います。

用語は[用語集](glossary.md)に集約します。変更時には対象となる訳文を検索し、UI・字幕・文書を横断して表記を直します。最終的な文字欠け、はみ出し、改行、文脈は製品版の通しプレイで検証します。
