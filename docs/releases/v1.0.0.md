# 製品版向け日本語化パッチ v1.0.0

Clive Barker's Hellraiser: RevivalのWindows／Steam製品版向け初回リリースです。

## 対応内容

- 対応ゲーム版: `1.0.1.227219_HellraiserGame_Shipping_27809_ReleasePatch1_Test`
- UI・字幕・文書などGame 6,846件、Engine入力表示164件、計7,010件の日本語訳
- 同梱NotoSansJPを利用するフォント参照設定
- 製品版のSteam自動検出、導入・更新・削除スクリプト
- 個人への宗教的敬称を「シスター・シャーロット」「ブラザー・エイダン」などに統一

## 導入

ゲームを終了し、配布ZIP全体を展開して `Install.cmd` を実行します。ゲーム内の言語設定で **「日本語」** を選択してください。削除には `Uninstall.cmd` を使用します。詳細はREADMEを参照してください。

デモ版には[デモ版専用パッチ](https://github.com/zombine04/hellraiser-revival-japanese-patch-demo)をご利用ください。

## 確認範囲と既知の制限

メニューとユーザーがプレイした範囲で、日本語表示・翻訳内容を確認しています。製品版の全編通しプレイと全分岐の確認は未完了です。

- 配信ニュースは中国語が残ります。[Issue #5](https://github.com/zombine04/hellraiser-revival-japanese-patch/issues/5)
- セーブ日時に「上午」など中国語表記が残ります。[Issue #6](https://github.com/zombine04/hellraiser-revival-japanese-patch/issues/6)
- 初回設定前のシェーダー準備・デモセーブ引き継ぎ確認に英語が残るとの報告があります。
- シェーダー画面の改行形式は修正済みですが、装飾タグ露出が解消したかの実機再確認は未完了です。
- 音声、画像内の文字、起動失敗・クラッシュ等の診断表示は対象外です。

ニュースと日時の問題は、ユーザーの方針により初回リリース後の対応としています。
