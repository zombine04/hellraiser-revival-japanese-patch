# 製品版 日本語化パッチ v1.1.0

メニューの配信ニュースを英語表示にし、セーブ日時・プレイデータ開始日時を数字と24時間制で表示します。日本語訳とフォント設定は引き続き適用されます。

## 導入・更新

ゲームを終了し、ZIP全体を展開して `Install.cmd` を実行してください。導入時にゲーム原本から必要な部分だけを読み、既存と同名の3ファイルへ統合します。追加のランタイムや通信は不要です。v1.0.0から更新でき、確認済みの英語表示試作も自動移行します。

ゲーム版または対象資産が一致しない場合は、変更前に停止します。未知・改変・欠落した試作も上書きしません。削除は `Uninstall.cmd` で行い、ゲーム本体・設定・セーブは変更しません。
