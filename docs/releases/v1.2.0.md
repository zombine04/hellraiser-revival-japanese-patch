## 変更の概要

ゲーム更新後も日本語化パッチを導入しやすくし、一部の字幕・メニュー・壁のメッセージの訳を修正しました。

## 変更箇所

- インストーラー：ゲームのバージョン番号が変わっても、ニュース・日時の表示に互換性があれば従来どおり導入できるようにしました。
- インストーラー：ニュース・日時の表示に互換性がない場合も、日本語訳とフォント設定を導入できるようにしました。この場合、ニュース・日時はゲーム標準の表示になります。
- 壁のメッセージ：依存をめぐる2つの文章を、文脈に合う表現に修正しました。
- ゾーラのストア：未販売の表示を「近日公開」から「近日販売」に修正しました。
- ニュース欄：非表示にする操作の表記を「隠れる」から「隠す」に修正しました。
- 武器ステータス：「力ずくで開ける」を「衝撃力」に修正しました。
- オルゴールへの反応：皮肉が伝わるように、字幕を「ふん…いい趣味してるな」に修正しました。
