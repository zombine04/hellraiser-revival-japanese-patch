# 製品版の解析と表示試作

## 原本と移行

- 対応版: `1.0.1.227219_HellraiserGame_Shipping_27809_ReleasePatch1_Test`
- Windows／Steam製品版のAppID: `1551980`。デモのAppID `5184670` とは分離する
- Pak v11、索引・対象LocResは暗号化なし、本文はOodle圧縮
- Gameの英語・簡体字中国語は各6,846件。識別キーと原文ハッシュはすべて一致
- デモ版からの差分: 不変6,831件、変更3件、追加12件、削除6件
- Engine全54,314件からPC入力表示164件を選択。選択範囲はデモ版から不変
- 同梱のNotoSansJP Regular／Boldと既存フォント参照・字幕スタイル表の対象チャンクはデモ版と一致。会話ウィジェットは変更されているため、字幕の製品版実機検証は別途必要

公開カタログには識別情報、ハッシュと書式制約だけを収録します。原文、抽出資産、解析結果、個人環境のログは `.local/` のみに保管します。抽出と移行の手順は[ビルド手順](build.md)を参照してください。

## 日本語表示と導入

GameとEngineの `zh-Hans` LocResを日本語訳に置き換えます。ゲームの言語選択肢は「日本語」と表示します。`EBGaramond_Font` と `FiraSansCondensed_Font` の参照設定を自作し、`zh-Hans` にゲーム同梱のNotoSansJPを指定します。フォント本体や抽出した元アセットは配布物へ収録しません。

配布識別名は `Hellraiser_Revival_Japanese_P`、管理状態は `.hellraiser-revival-japanese-patch.json` とし、デモ版と区別します。Steamの製品版マニフェストから実際のインストール名を読み、デモ版・製品不明のフォルダーやデモ版パッチとの混在を拒否します。製品版と確認できる未対応ビルドだけが明示的な続行確認の対象です。

試作は `scripts/build.py --preview` または `scripts/build_probe.py` で同じ導入・削除処理を含むZIPとして作成します。古い手動導入用の試作コンテナは作成しません。ローカルではSteam自動検出による導入に成功し、ユーザーがメニューの日本語表示を確認しています。

## 起動時の英語表示

ユーザーによる初回設定前は、シェーダー準備画面とデモ版セーブ引き継ぎの確認が英語でした。対応する日本語訳はGame LocResに存在します。初回設定後は簡体字中国語の言語枠が保存され、メニューは日本語になりました。設定前の言語選択・反映時期が関係している可能性がありますが、再起動時と新規設定時の比較は未実施です。原因確定・解消済みとは扱いません。

## シェーダー画面の装飾タグ露出

`W_WelcomeScreen` は `ST_UI_Unique.shader_precompilation` を取得し、装飾名 `Shader` を `W_WelcomeScreen_Description.SetText` に渡します。同ウィジェットの `ParseText` はCRLFで行を分割し、各行に装飾を付けます。原文はCRLFですが、公開訳文はLFで管理していたため、出力にもLFだけが残っていました。

`jp_patch/runtime_text.py` はこのキーの既知の原文ハッシュを確認し、LocRes出力時だけLFをCRLFへ変換します。原文が更新された場合はビルドを止め、表示処理を再調査します。原文ハッシュ・タグ・公開訳文の管理形式は変更しません。LocRes往復後に2行へ分割できる回帰試験を追加しています。

これはタグ露出の修正候補です。導入済みの試作はこの変更前であり、更新した試作の実機確認は未実施です。初回設定前の英語表示を解決する変更とは区別します。

## ニュース欄

表示ウィジェット `W_MOTD` とスタイル設定はローカルに存在します。本文とバナーは `ProsBannerService.GetSpaces` の受信結果から組み立て、画像は `AsyncTaskDownloadImage.DownloadImage` で取得します。言語はゲーム設定と `FromLanguageToCultureCode` から選択しています。ニュース本文は通常のGame LocResに含まれる固定文ではなく、PROSの配信データを表示する構造です。

日本語化に簡体字中国語の言語枠を使うことで、配信ニュース側も中国語を選んでいると考えられます。ローカルキャッシュの有無と配信内容の全量は未調査です。既存のLocRes翻訳だけで最新ニュースも日本語化できるとは扱いません。言語の切り替えや非表示化は本変更には含めません。

## セーブ日時の「上午」

「上午」は中国語の午前表記です。`W_SaveLoadScreenSaveSlotButton.InitLabels` は保存日時を `KismetTextLibrary.AsTime_DateTime` と `AsDate_DateTime` に渡して表示し、プレイスルー一覧も同じ日時変換を使っています。固定のLocRes訳文ではありません。

Unreal Engineでは言語とは別にlocaleが数値・日時の書式を決定します。[Epic公式のUE5.6資料](https://dev.epicgames.com/documentation/en-us/unreal-engine/managing-the-active-culture-at-runtime?application_version=5.6)にこの区別と設定方法が説明されています。簡体字中国語の言語選択に日時書式が連動していると考えられます。日本語の日時書式をゲーム側が維持できるかを含め、対応は未完了です。セーブデータ自体の変更は行いません。

## 製品版で残っている確認

- シェーダー改行修正後の実機表示と、起動直後の言語反映
- 配信ニュースの扱いと、セーブ日時の日本語書式
- パズル追加訳1件の文脈、字幕・文書・設定・入力表示の再確認
- 製品版での削除後復帰・再導入・セーブ再開と、ユーザーによる通しプレイ
- 最終配布候補の照合とユーザーの公開承認

デモ版で成功した検証結果を、上記の製品版検証の代わりにはしません。
