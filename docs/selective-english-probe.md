# ニュース・セーブ日時の局所変更試作

製品版のIssue #5・#6を対象に、2026年10月9日に表示処理だけを変更する試作を行いました。正式ビルド・配布物への組み込みは未実施です。

## 対象と方式

対象版は `1.0.1.227219_HellraiserGame_Shipping_27809_ReleasePatch1_Test` です。既存の日本語訳とNotoSansJP設定を維持し、次の3ウィジェットだけをローカルの追加コンテナで置き換えました。

| ウィジェット | 変更 |
|---|---|
| `W_MOTD` | ニュースの本文・画像・遷移先に使う言語参照を英語に固定 |
| `W_SaveLoadScreenSaveSlotButton` | セーブ日時を年・月・日、24時間制の時・分・秒から組み立て |
| `W_SaveLoadScreenPlaythroughSlotButton` | プレイデータ開始日時に同じ書式を適用 |

ニュース本文の翻訳、ニュース画像の加工、字幕・メニュー全体の英語化は行いません。日時は `YYYY-MM-DD` と `HH:mm:ss` の2行で表示します。英語の月名やAM/PMを含むlocale書式ではなく、言語に依存しない数字の書式です。保存日時の値、タイムゾーン、プレイ時間、セーブ内容は変更しません。

## 確認結果

- `-language=zh-Hans -locale=en` を指定した起動だけでは、セーブ日時の中国語表記が残りました。
- 修正版試作で起動とロード画面の表示に成功しました。既存の手動セーブ・オートセーブ・プレイデータの日時が数字の書式になり、項目名、難易度、説明は日本語のまま表示されました。
- ニュースは試作追加前から配信サービスへの接続に失敗しました。ニュース単独の試作でも同じ接続失敗となり、再接続操作では回復しませんでした。このため、実際の英語本文・画像・リンクの表示成功は未確認です。
- 最初の日時試作は、ゲームに存在しない関数参照を追加したため起動時にクラッシュしました。修正版では製品版に存在する日時要素の取得関数に置き換え、追加参照の存在を照合しています。
- 試験前後のセーブ14ファイルのSHA-256が一致しました。既存パッチと原本を含むPaks内33ファイルのサイズ・更新日時も一致し、設定ファイルは退避時の内容へ戻しました。
- Steamの起動コマンドではゲーム画面を確認できませんでした。実機表示確認は実行ファイルからの起動で行っており、Steamからの通常起動と再起動後の継続確認は残っています。
- 生成した3資産をCUE4Parseで読み戻し、関数末尾、分岐先、変更対象を確認しました。日時5か所について、午前・正午・深夜・ゼロ埋めを含む4例の式評価を照合しました。

`W_MOTD.GetLanguageKey` は受信データの言語を分類する処理です。ここで中国語と英語の対応を入れ替えると受信内容を誤分類するため、変更しません。表示側の `GetLanguage` 参照7か所を英語へ固定します。

日時は `InitLabels` 内の `AsTime_DateTime` / `AsDate_DateTime` 呼び出し5か所を変更します。`GetYear`、`GetMonth`、`GetDay`、`GetHour`、`GetMinute`、`GetSecond` と文字列組み立てを使用するため、ゲーム全体のlocaleは変更しません。UEの言語とlocaleの区別は[Epic公式資料](https://dev.epicgames.com/documentation/en-us/unreal-engine/managing-the-active-culture-at-runtime?application_version=5.6)を参照してください。

## 試作の保存と制限

抽出物、生成資産、試作コード、ハッシュ、設定・セーブの退避、実機記録は `.local/selective-english/` に保存します。公開するのはこの調査記録だけです。元資産を含む試作コンテナはGit・GitHub・配布ZIPへ収録しません。

確認済みの修正版試作3ファイルはローカル環境に適用した状態です。ゲームは終了しています。ローカルの `Restore-Probe.cmd` はゲーム終了とハッシュ一致を確認し、今回追加した3ファイルだけを削除します。

試作の識別名は `Hellraiser_Revival_EnglishProbe_P` です。既存の日本語パッチと管理情報には上書きしません。試作の3ファイルだけを取り除けば、導入前の表示処理に戻ります。正式インストーラーの管理対象ではないため、試作を正式パッチとして配布しません。

この試作では、他言語へ切り替えても対象ウィジェットのニュースは英語、日時は数字書式になります。正式採用前に、日本語選択時だけ変更するかを決める必要があります。

残っている確認は、配信接続が成功する状態でのニュース本文・画像・リンク、ゲーム内の言語変更、新規保存画面、セーブ再開、ユーザーによる確認です。ニュースの英語表示成功やIssue #5・#6の解決済みとは扱いません。正式版への組み込みには、原本を再配布せず導入先で変更を生成する方式などの設計と検証が必要です。
